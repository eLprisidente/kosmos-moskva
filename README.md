# Поехали! Космическая Москва: от подвала до орбиты

Проект по курсу «Основы российской государственности» (НИУ ВШЭ, КНАД, гр. 263).
Тема 1: интерактивный путеводитель — историко-культурный маршрут по Москве, 11 остановок, 5 глав.

## Структура

```
index.html                 точка входа сайта (разметка страницы)
css/style.css              оформление: цвета, шрифты, светлая и тёмная темы
js/config.js               настройки: ключ Яндекс Карт, центр и масштаб карты
js/data.js                 содержание: главы, остановки, тексты, квиз, хронология, источники
js/credits.js              авторы, лицензии и источники фотографий
js/app.js                  логика: карта, карточки, квиз, хронология, список источников
photos/01.jpg … 11.jpg     фотографии остановок
tools/download_photos.py   подбор фото с Wikimedia Commons (свободные лицензии)
run.py                     локальный запуск сайта
План_проекта.docx          концепция и критерии оценивания
```

Тексты и факты меняются только в `js/data.js` — остальной код трогать не нужно.

## Запуск

Правый клик по `run.py` → **Run**. Откроется браузер на `http://localhost:8000/`
(если порт занят — на следующем свободном). Остановка — кнопка **Stop**.

## Фотографии

- Скачать недостающие фото с Commons: правый клик по `tools/download_photos.py` → **Run**.
  Уже существующие фото скрипт не перезаписывает.
- Заменить фото с Commons: впишите в скрипт `OVERRIDES = {номер: "File:Имя файла.jpg"}` и запустите.
- Своё фото не с Commons: положите его как `photos/NN.jpg` и добавьте запись в `js/credits.js`:

```js
"10": {"file": "photos/10.jpg", "title": "Название снимка", "author": "Автор",
       "license": "", "source": "Название сайта", "page": "https://ссылка-на-страницу-с-фото", "w": 1280, "h": 853}
```

Подписи «Рисунок N — …» и список иллюстраций по ГОСТ Р 7.0.100–2018 сайт строит сам.

## Яндекс Карты

Ключ JavaScript API лежит в `js/config.js`. Тариф бесплатный: до 100 загрузок карты в сутки.
Разрешённые адреса ключа (HTTP Referer) настраиваются в кабинете developer.tech.yandex.ru:
сейчас там `localhost`, после выкладки нужно добавить домен хостинга.
Если карта не загрузилась (лимит, нет сети), сайт автоматически показывает собственную SVG-схему.

Условия бесплатного тарифа: сайт в открытом доступе, логотип и копирайты Яндекса не скрываются,
скриншоты карты не используются (на защите карту показываем вживую).

## Хостинг

Сайт статический: сервер и база данных не нужны. Загружаются `index.html`, `css/`, `js/`, `photos/`
(`run.py`, `tools/` и `.docx` не нужны). Подойдут GitHub Pages, Netlify, Яндекс Object Storage.
При обновлении файлов на хостинге увеличьте `?v=` в ссылках на css/js в `index.html`,
чтобы браузеры не показывали старую версию из кэша.

## Технологии

HTML, CSS и JavaScript без фреймворков. Карта — Яндекс Карты JavaScript API 2.1.
Запасная карта — SVG, который строит скрипт: широта и долгота переводятся в пиксели
равнопромежуточной проекцией с поправкой cos(φ).
